# forcodex

Codex test, erişim, video kayıt, screenshot, log ve doğrulama dosyaları bu klasörde tutulur.

- `scripts/`: Web Bot Auth, HTTP erişim testi ve Playwright video test scriptleri
- `screenshots/`: Playwright ekran görüntüleri
- `videos/`: Playwright video kayıtları (git dışı)
- `reports/`: Markdown raporları
- `logs/`: Çalışma ve hata logları
- `verification/`: Dosya/erişim doğrulama çıktıları

Public storefront kapsamı dışındaki `/admin`, `/checkout`, `/cart`, `/account`, `/login` gibi alanlara istek atılmaz.
